# packs_verification
Verification of simple algorithm of pack intervals determination - it is
described [here](https://disco85.github.io/myblog/Programming/Packs_Search.html).

Its Python implementation is [packs.py](packs.py).

There are other ways to determine packs, but the focus of this repository is
verification practice.

# Why3 verification

[Packs.mlw](Packs.mlw) is verification of the algorithm with
[Why3](https://why3.org/) using WhyML language.
